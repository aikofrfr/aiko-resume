Aiko's DisplayName Mod / Configuration

Configuration

Most settings can be changed in-game. The editor saves changes to the active Minecraft instance automatically.

Open the editor

Press Right Shift. Change the key from Minecraft's Controls menu if another mod uses the same binding.

Editor sections

  • Overview: quick switches, active template, scale and preset import/export.
  • Appearance: gradient, background, border, palette, scale and opacity.
  • Elements: badge and health display toggles, symbol and health format.
  • Animations: animation toggle, gradient toggle and speed.
  • Visibility: sneaking, self-nameplate, maximum distance and distance fading.
  • Layouts: cycle or reapply included templates and import/export presets. This is not a drag-and-drop editor.
  • Players: edit local name, badge, colour and visibility for the selected player.

Configuration files

FilePurpose
config/aikos-displayname.jsonMain settings file.
config/aikos-displayname-export.jsonPreset exported from the editor.
config/aikos-displayname.invalid.jsonBackup created when the main configuration cannot be parsed.

Reset settings

Use Reset settings in the editor. For a manual reset, close Minecraft, back up the JSON file and move only aikos-displayname.json out of the config directory. A fresh file is created on the next launch.

Share a preset

  1. Choose Export preset.
  2. Locate aikos-displayname-export.json in the instance's config directory.
  3. Share the file with someone you trust.
  4. They can place it in their own config directory and use Import preset.
