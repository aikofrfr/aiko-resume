Aiko's DisplayName Mod / FAQ

Frequently asked questions

Is this a client-side mod?

Yes. The mod is marked client-only in Fabric metadata. The server does not need it for local visual features.

Does one JAR cover Minecraft 1.21.x?

The metadata declares >=1.21 <1.22 and the source has handler variants for the renderer generations in the 1.21 line. Individual patch compatibility still needs in-game verification; see Compatibility.

What opens the editor?

Right Shift by default. Change it in Minecraft's Controls menu if needed.

Can I assign a custom rank badge to another player?

You can add a local visual badge on your own client. It does not grant or verify a real server rank or staff permission.

Can I see everyone else's health?

No. Remote health is only shown when the server sends a suitable below-name health scoreboard objective. The mod does not bypass server-side restrictions.

Are custom image badges and fonts supported?

Not in the current build. The current badge is a configurable text symbol; custom image uploads and custom font loading remain future work.

Does it work with Sodium or Iris?

Those combinations have not been fully tested. Check the compatibility page and include exact mod versions when reporting an issue.
