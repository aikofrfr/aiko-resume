1.1.0+1.21.x · Current source version

  • Added the single-JAR metadata target for Minecraft 1.21.x.
  • Added alternate nameplate renderer handler signatures for rendering changes in the 1.21 line.
  • Added in-game editor sections for overview, appearance, elements, animations, visibility, layouts and players.
  • Added five starting templates.
  • Added gradient palettes, badge symbols, health formatting and local player overrides.
  • Added JSON validation, invalid-file backup and preset import/export.
The maintainer reported a successful Gradle build using Temurin JDK 21.0.13 on Windows. Each Minecraft patch still needs a real launch test before being called verified.
