Aiko's DisplayName Mod / Features

Features

A guide to controls in the current source build. Implemented behaviour is separated from ideas that remain future work.

Nameplate appearance

  • Fixed name colour or animated two-colour gradient.
  • Selectable gradient palettes.
  • Background opacity and border controls on the classic rendering path.
  • Overall nameplate scale and distance-based fading.

Badges and player overrides

  • Configurable text-symbol badge and colour.
  • Local player-specific display name, badge, colour and visibility settings.
  • Overrides are stored locally by player UUID and are not sent to the server.

Health display

  • Local health can be shown from local player data.
  • Remote health is shown only when a below-name scoreboard objective using Minecraft's health criterion is available to the client.

Not in the current build

Drag-and-drop positioning, custom image uploads, custom font loading and arbitrary per-element transforms are not implemented in this build. Treat these as future work, not available options.
