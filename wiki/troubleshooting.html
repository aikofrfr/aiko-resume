Troubleshooting

The mod does not appear in-game

  1. Confirm you launched the Fabric profile rather than Vanilla, Forge or NeoForge.
  2. Make sure the JAR is directly inside the active instance's mods folder.
  3. Check that Fabric API matches the Minecraft patch.
  4. Confirm your launcher is using the directory where you installed the JAR.
  5. Search logs/latest.log for aikosdisplayname or a mod-loading error.

Right Shift does not open the editor

  • Check the Controls menu for the Aiko's DisplayName Mod binding.
  • Look for a key conflict with another mod.
  • Confirm the mod loaded successfully before entering a world.
  • Check the latest log for an exception during client initialisation.

Nameplates differ between versions

The 1.21.9–1.21.11 renderer path currently retains Minecraft's vanilla text background and does not draw the custom quad border/background used on the earlier path.

Remote health is missing

The server must provide a below-name scoreboard objective using the health criterion. Without it, the mod cannot display remote health.

Build error: Unsupported class file major version 69

This error occurs when Gradle is launched with Java 25. Use JDK 21 for this project, open a new Command Prompt and confirm with java -version before running scripts/build-all.bat.

Build succeeds but no JAR appears

Check build-output.log and build/libs. The release script copies the compiled JAR only after Gradle succeeds. Share the final 40–60 lines of the log when asking for help.

When reporting a problem

Include the exact Minecraft version, mod version, Fabric Loader and API versions, launcher, installed mods, steps to reproduce and logs/latest.log. Remove private information from logs before sharing them.
