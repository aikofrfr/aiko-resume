Aiko's DisplayName Mod / Installation

Installation

Aiko's DisplayName Mod is a Fabric client mod for Minecraft Java Edition 1.21.x. The server does not need the mod installed for its local visual features.

Requirements

  • Minecraft Java Edition on a compatible 1.21.x version.
  • Fabric Loader for the same Minecraft version.
  • Fabric API matching the exact Minecraft patch.
  • Java 21 for Minecraft 1.21.x.
  • The compiled mod JAR from the project's release/build output.

Install Fabric

  1. Download the Fabric Installer from fabricmc.net.
  2. Select the Minecraft version you intend to use and install a client profile.
  3. Start that profile once, then close Minecraft.

Add the mod

  1. Open the game directory used by your Fabric profile.
  2. Open or create the mods folder.
  3. Place the Aiko's DisplayName Mod JAR directly inside it.
  4. Add the matching Fabric API JAR if it is not already installed.
  5. Launch Minecraft using the Fabric profile.
%appdata%\.minecraft\mods

Third-party launchers often keep separate instance directories. Use the folder configured by that launcher rather than assuming the default path.

Open the editor

Press Right Shift in-game. If nothing opens, check the Controls menu for a key conflict and inspect logs/latest.log for a loading error.

Updating

  1. Close Minecraft completely.
  2. Back up config/aikos-displayname.json.
  3. Remove the older mod JAR from the instance's mods folder.
  4. Add the new JAR and read its release notes.
  5. Keep only one copy of the mod in the folder.
