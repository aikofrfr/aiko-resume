Aiko's DisplayName Mod / Compatibility

Compatibility

The mod metadata declares >=1.21 <1.22. This is the 1.21.x target range. A declared range is not proof that each patch has been tested in-game.

Dependencies

  • Fabric Loader version appropriate for the selected Minecraft patch.
  • Fabric API matching that exact patch.
  • Java 21.

Rendering mods

Sodium, Iris, shader packs and other nameplate modifications can alter rendering behaviour. Compatibility has not been confirmed for every combination. If a visual issue occurs, test with only Fabric Loader, matching Fabric API and this mod enabled, then re-add other mods in small groups.

Known renderer difference

On Minecraft 1.21.9–1.21.11 the current hook styles the queued name text but retains the vanilla text background. The custom quad background and border used on the earlier path are not drawn there.

Release checklist: Add a patch to the verified list only after launching that exact version and checking that the editor opens and nameplates render correctly.
