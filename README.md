# Aiko's Portfolio

A responsive personal portfolio and printable developer CV for Aiko. It highlights five years of development experience, Java and C++, custom Minecraft plugin and mod development, plugin configuration and troubleshooting, custom Discord bot development, web and graphic design, and previous Minecraft server roles.

## Files

- `index.html` — main responsive portfolio
- `styles.css` — styling, responsive layouts and animations
- `script.js` — navigation, theme toggle, scroll effects and Discord copy control
- `cv.html` — printable CV (browser Print → Save as PDF)
- `404.html` — GitHub Pages not-found page
- `assets/favicon.svg` — browser tab icon

The top-left avatar uses Aiko's public GitHub profile image. The header and mobile "Let's talk" links open the Discord server invite. The contact section displays the Discord handle `yourstruly.aiko`.

## Preview locally

Open `index.html` in a browser. No build step, Node.js, paid API or subscription is required.

## GitHub Pages

Publish from the `main` branch and repository root (`/(root)`). The site URL is:

https://aikofrfr.github.io/aiko-resume/

## Updating content

Edit `index.html` for portfolio content and `cv.html` for the printable CV. Edit `styles.css` for visual styling. The Discord handle copy control is configured in `script.js`.
